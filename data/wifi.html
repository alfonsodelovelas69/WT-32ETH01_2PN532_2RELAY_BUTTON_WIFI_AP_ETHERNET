WiFi для резервного підключення

Ethernet залишиться основним, якщо він підключений. WiFi як резерв буде використано лише після того, як ви вручну виберете та збережете свою мережу на цій сторінці. Старі збережені дані без такого підтвердження не використовуються.

Виберіть власну мережу зі списку або введіть її назву. Для відкритої мережі залиште пароль порожнім. Для тієї самої мережі порожнє поле залишає попередній пароль.

Email-повідомлення про адресу пристрою

Після отримання або зміни IP через Ethernet чи підключену WiFi-мережу пристрій надішле адресу вебсторінки. У режимі точки доступу без інтернету email надіслати неможливо.

Повна адреса Gmail-скриньки, з якої пристрій надсилатиме листи, наприклад my_device@gmail.com.

Важливо: введіть 16-символьний пароль застосунку Google, створений у налаштуваннях безпеки Google-акаунту в розділі «Паролі додатків». Для цього має бути ввімкнена двоетапна перевірка. Звичайний пароль Gmail не підійде. Вводьте код без пробілів.

Повна адреса скриньки, на яку пристрій надсилатиме повідомлення, наприклад admin@gmail.com. Наразі листи містять нову або змінену IP-адресу пристрою; скорочення країни/регіону, розпізнане з номера авто, email-сповіщенням поки не надсилається.

Після збереження пароль застосунку зберігається у пам’яті пристрою і не показується у формі. Порожнє поле пароля залишає раніше збережений пароль; очистіть обидві адреси, щоб вимкнути сповіщення.
